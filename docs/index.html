功能

三招对付烦人的广告。

自动跳过开屏广告

通过无障碍服务识别"跳过 / 5s 跳过 / Skip"等按钮并自动点击。

对付"摇一摇"广告

页面出现"摇一摇 / 摇动手机 / 扭一扭"时，更积极地寻找跳过按钮。

拦截陀螺仪 可选

LSPosed 模块：在你勾选的应用中屏蔽陀螺仪、加速度计、旋转矢量等运动传感器，让摇一摇广告彻底失效。

安装与使用

四步装好，第四步可跳过。

01

下载安装

下载 AdSkipper-v1.0.apk 并安装

如提示"未知来源"，允许浏览器安装应用。

下载 APK v1.0

02

开启服务

开启无障碍服务

打开应用，点"开启无障碍服务"，找到"广告跳过助手"打开。

03

华为 / 荣耀等机型

防止被后台清理

设置 → 应用 → 应用启动管理，把它设为手动管理并全部允许。

04

可选

启用 LSPosed 模块

  • 需要 Root
  • 需要 LSPosed

LSPosed 管理器 → 模块 → 启用"广告跳过助手" → 勾选广告多的应用 → 强行停止这些应用后重新打开。

小技巧与注意事项

没有 Root 也能关传感器。

没有 Root 的小技巧

开发者选项 → 快捷设置开发者图块 → 打开"传感器已关闭"。需要时在下拉栏一键关闭所有传感器。

注意事项

被 LSPosed 勾选的应用会失去重力感应。 体感游戏、计步、摇一摇等功能也会失效。
